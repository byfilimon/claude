# Замер — замер помещений под мебель

Веб-приложение (PWA) для замерщика: подключается к лазерной рулетке **Bosch GLM 50 C** по Bluetooth,
подставляет замеры в план комнаты и выгружает результат в **DXF для Базис-Мебельщика**.

## Что умеет (черновая версия)

- Заказы: клиент, телефон, адрес, несколько помещений (прямоугольные, Г-образные, произвольные).
- План комнаты: стены замеряются по часовой стрелке, замер с рулетки попадает в подсвеченное поле,
  и курсор сам переходит к следующей стене → высота потолка.
- Углы между стенами (90°, 270° для выступов, 135° и т.д.), кнопка «Прямоугольник» (C = A, D = B).
- Окна, двери, ниши, розетки, трубы: отступ от угла, ширина, высота, высота от пола; развёртка стены.
- Проверки: незамкнутый контур, элемент за краем стены или выше потолка. Площадь и периметр.
- Экспорт DXF (R12, cp1251): план + развёртки всех стен, слои `WALLS`, `OPENINGS`, `DIMS`, единицы — мм.
- Работает без интернета (service worker), данные хранятся на устройстве (localStorage).
- «Симулятор» рулетки — чтобы проверить работу без прибора.

## Рулетка

Web Bluetooth работает в **Chrome на Android** (и Chrome/Edge на ПК). На iPhone — только через браузер Bluefy.
Приложение должно открываться по **HTTPS** (или `localhost`).

Протокол GLM 50 C Bosch не публикует; драйвер (`src/ble/glm.ts`) сделан по открытым
реверс-инжиниринговым данным. Если замеры не приходят — откройте журнал (кнопка ≡ в шапке),
сделайте замер и пришлите строки `←` с hex-пакетами: по ним парсер легко поправить.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты геометрии, парсера GLM и DXF
npm run build    # сборка в dist/
```

## Деплой на VPS (zamer.2pietro.com.pl)

Локально (нужен SSH-доступ к серверу):

```bash
npm ci && npm run build
VPS_HOST=46.36.220.54 bash deploy/deploy.sh
```

`deploy/server-setup.sh` на сервере: находит сайт домена в nginx/apache (в т.ч. созданный панелью) и
берёт его каталог, либо создаёт vhost nginx с корнем `/var/www/zamer`; выкладывает файлы; выпускает
сертификат Let's Encrypt, если его нет (HTTPS обязателен для Web Bluetooth).

Автоматически: `.github/workflows/deploy.yml` делает то же при каждом пуше, если в секретах репозитория
заданы `VPS_HOST` и `VPS_SSH_KEY` (или `VPS_PASSWORD`).
